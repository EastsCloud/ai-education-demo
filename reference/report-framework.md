# AI Education Report Framework / 学习报告框架

本文档定义 AI Education 的报告思路。它参考美国常见教育测评和学习平台的公开报告逻辑，例如 MAP Growth、Renaissance Star、i-Ready，但不照搬它们的报告。AI Education 的报告要结合我们自己的三件事：

```text
一对一画像
练中学行为
帮你学过程数据
```

---

## 1. 外部报告给我们的启发

### 1.1 MAP Growth

MAP Growth 的公开介绍强调：

- 用统一成长尺度衡量学生跨年级成长。
- 看学生当前水平，也看一段时间内的成长。
- 报告服务于学生、班级、学校和地区等不同层级。
- 报告要支持下一步教学决策。

我们可以借鉴：

- 把“当前水平”和“成长速度”分开。
- 用学习曲线展示从起点到目标的路径。
- 同时支持学生端简版和家长 / 老师端深版。

### 1.2 Renaissance Star

Star 报告公开介绍里强调：

- Scaled Score：跨年级共同尺度。
- Percentile Rank：和全国样本比较。
- Student Growth Percentile：和相似历史学生比较成长。
- Domain scores：展示具体技能领域的掌握情况。

我们可以借鉴：

- 报告里要有同类学生参照，但不做压力型排名。
- 能力维度要分开看，而不是只给总分。
- 成长要和相似学生比较，而不是只和平均学生比较。

### 1.3 i-Ready

i-Ready 公开介绍里强调：

- 显示学生相对年级水平的位置。
- 给出 Typical Growth / Stretch Growth 这样的目标语言。
- 把诊断结果连接到下一步教学资源。
- 让老师、学生和家长共同理解目标。

我们可以借鉴：

- 报告要有“目标路径”和“下一步动作”。
- 目标不只是水平，还包括可达成的学习强度和时间。
- 报告要告诉学生下一步做什么，而不是停在结果描述。

## 2. AI Education 的报告原则

### 2.1 图像优先

学生和家长先看简单图像，再展开文字。

第一屏不做密集报告卡，优先展示：

- 学习时长
- 当前进度
- 整体正确率
- 同类学生水平
- 能力维度趋势
- 知识点完成图

### 2.2 行动导向

报告不是评价学生好坏，而是回答：

```text
我现在在哪里？
我离目标还有多远？
我哪里进步了？
我卡在哪里？
下一步做什么？
```

### 2.3 分角色

学生端：

- 只看鼓励性、行动性的摘要。
- 不暴露后台风险标签。
- 不强调“乱猜”“不稳定”等负面标签。

家长 / 老师端：

- 可以看更完整的行为模式。
- 可以看测试结果、能力维度、学习节奏和介入建议。
- 可以看系统为什么建议调整时间、强度或测试间隔。

### 2.4 测试与练习分开

报告要明确区分：

- 阶段测试：更新动态学习曲线。
- 每日练习：影响明天出题、提示策略和画像。

每日练习表现不能直接改变动态曲线。

## 3. 第一版报告模块

报告不应理解为一张固定页面，而是一套同源数据、分角色呈现的报告系统。

同一批测试结果、练习行为、提示记录和学习曲线数据，需要生成三种表达：

```text
学生端：看进步、下一步、温和参照
家长端：看真实状态、支持方式、节奏是否合适
老师端：看能力卡点、教学介入、题型和班级共性
```

家长和老师的底层能力基本一致，可以共用“观察端”结构；区别主要在默认展示模块和语言风格。

### 3.1 当前水平卡

展示：

- 当前能力水平
- 目标水平
- 离目标还差多少
- 当前处于静态曲线 / 动态曲线的什么位置

图形：

- 双曲线小图
- 目标达成进度环

### 3.2 成长趋势卡

展示：

- 最近几次测试结果
- 动态曲线是否高于或低于静态曲线
- 是否需要建议测试

图形：

- 静态曲线 + 动态曲线叠加
- 测试节点标记

### 3.3 学习投入卡

展示：

- 本周学习时长
- 平均每日学习时长
- 学习频率
- 是否主动加练
- 是否中断较多

图形：

- 每日学习时长柱图
- 连续学习点阵

### 3.4 正确率与复现卡

展示：

- 整体正确率
- 做对题复现率
- 错题重做成功率
- 变式迁移成功率

图形：

- 正确率折线
- 四项小指标

### 3.5 同类学生参照卡

展示：

- 同年龄 / 同目标 / 同阶段学生中的相对位置
- 同类学生同题型正确率
- 同类学生学习时长区间

边界：

- 学生端不做硬排名。
- 表达为“参考位置”，不是“竞争排名”。

图形：

- 温和区间标记
- “你在这里”的位置点

### 3.6 能力维度趋势卡

展示：

- 读题翻译
- 找逻辑关系
- 列方程
- 计算
- 变式迁移
- 提示独立性

图形：

- 雷达图或维度条
- 前后对比小趋势

### 3.7 知识点完成卡

展示：

- 知识拼图完成度
- 已掌握知识点
- 当前知识点
- 可探索知识点
- 错题集入口

图形：

- 平面知识拼图
- 知识节点地图

### 3.8 帮你学行为卡

展示：

- 提示打开层级
- 是否先看历史原题
- 是否进入分步引导
- 常卡步骤
- 常用解题思路

图形：

- 步骤卡点条
- 提示层级分布

### 3.9 下一步建议卡

展示：

- 明天重点练什么
- 是否建议测试
- 是否调整每日强度
- 是否建议家长 / 老师介入

图形：

- 1-3 条行动按钮或短建议

当前实现的边界：

- 家长和老师端最多显示三条建议，先给当前学习重点，再按可信行为证据补一条支持动作；学习节奏出现连续遗漏时，优先提示先调整可完成的频率。
- 可信作答不足四次时，只提示继续积累记录，不对学习方式下结论。
- 建议不改变学生的学习曲线，也不把“快速作答”“提示较多”等信号作为学生标签。

## 4. 报告数据结构

第一版报告数据可以包含：

```text
reportId
studentId
period
generatedAt
audience
currentLevel
targetLevel
growthCurve
studyTime
accuracy
reproduction
peerReference
abilityTrends
knowledgeProgress
helpBehavior
behaviorSignals
nextActions
visibilityRules
```

### 4.1 角色化报告结构

第一版可以把报告拆成 4 层：

```text
ReportSnapshot
-> studentSummary
-> observerSummary
-> evidence
-> nextActions
```

**studentSummary**

给学生看的内容，必须轻、短、行动导向。

- 当前进度
- 本周进步
- 今天或明天做什么
- 温和的同类参照
- 历史测试结果
- 老师 / 家长留言
- 可选展开：错题、对题、突破题、今日涉及的知识图鉴

学生端不直接显示：

- 风险标签
- “瞎答”判断
- 复杂行为归因
- 家长 / 老师内部备注
- 完整画像

**observerSummary**

给家长 / 老师看的内容，可以更完整，但仍然先图形化。

- 测试结果和能力维度变化
- 静态曲线与动态曲线对比
- 学习投入：次数、停留时间、学习频率、加练
- 行为模式：答题时间、提示依赖、复现情况、错题重做
- 题型资源消耗：哪些题型花时间多、提示多、失败多
- 反馈效果：提示后是否能做对、分步引导是否有效
- 介入建议：鼓励复盘、暂缓加难、增加测试、调整节奏

**evidence**

报告不能只有结论，必须能回到证据。

- 最近测试节点
- 代表性错题
- 代表性对题
- 突破题
- 提示使用记录
- 学习时长和会话记录
- 与同类学生的温和参照

**nextActions**

所有报告最后都要落到动作。

- 学生下一步练什么
- 是否建议阶段测试
- 是否调整每日学习时间或总周期
- 家长 / 老师是否需要介入
- 是否进入某个知识点图鉴复盘

### 4.2 家长 / 老师观察端模块

观察端不需要一开始分成两套系统。第一版先做一个共用观察端，通过下拉菜单选择默认视图：

```text
家长简洁视图
家长详细视图
老师诊断视图
老师班级视图
```

家长默认关注：

- 是否按目标推进
- 是否真的在努力
- 哪些地方需要鼓励或陪伴
- 学习强度是否合适
- 下一阶段是否要测试或调整目标

老师默认关注：

- 学生卡在哪个能力维度
- 哪些题型需要人工讲解
- 提示是否有效
- 是否出现连续错误、跳步、复现失败
- 班级或同组学生是否有共性问题

### 4.3 页面入口原则

学生端主导航只保留“报告”，不拆“测试历史”“同类水平”“留言”“图鉴报告”等多个页面。

报告页内部再通过模块或展开层承载：

- 测试历史
- 同类水平
- 留言
- 知识图鉴入口
- 错题 / 对题 / 突破题
- 下一步建议

家长 / 老师端可以有“观察端”入口，但它不是学生端主导航的一部分。

---

## 5. MVP 报告优先级

MVP 先做 6 个卡片：

```text
1. 当前水平 / 目标距离
2. 学习曲线
3. 学习时长
4. 正确率与复现
5. 能力维度趋势
6. 下一步建议
```

知识拼图、同类学生水平和帮你学行为可以作为第一版增强模块。
