# AI Education Product Decision Checklist

This checklist maps discussed product decisions to the product flow. During future development, Codex should use this file to check whether a task touches an already-discussed decision.

## Status Legend

- `Not started`: discussed, but not implemented yet.
- `Prototype`: represented in the current prototype or mock data.
- `In build`: being implemented in real code.
- `Done`: implemented and verified.
- `Skipped`: intentionally not included in the current scope.

## How To Use During Development

Before implementing or reviewing a feature:

1. Find the related flow stage.
2. Check every decision under that stage.
3. If the task touches a decision, remind the user before implementation or during review.
4. Update `Status` and `Implementation note`.
5. If the task does not touch a decision, leave it unchanged.
