# 安全合规与数据治理

## 1. 文件性质

本文件是产品和工程准备清单，不是中国法律意见。正式试点、商业收费或向公众提供生成式 AI 服务前，应由具备中国教育、未成年人、网络安全和数据合规经验的律师及安全机构复核。

## 2. 当前版本的安全边界

已经实现：

- 账号密码以哈希形式保存
- 服务器会话和登录失败限流
- 学生、家长、老师按关系授权访问
- 家长不能读取其他家庭学生
- 学生可以在没有家长或老师的情况下完成学习
- 正确答案、生成种子、私有提示和行为分类不返回浏览器
- 浏览器不能自行声明“答对”或“达到水平”
- 每日练习不能直接改变动态曲线
- 数据持久化到 SQLite，测试快照与运行副本分离

尚未实现：

- HTTPS、生产 Cookie、密钥管理和多因素认证
- 组织租户、学校隔离和生产审计导出
- 生产备份、恢复演练、告警、限流和 WAF
- 用户个人信息查询、导出、更正、撤回和删除的完整自助流程
- 监护人同意管理及未成年人专门隐私规则
- 教育应用、ICP、等级保护、算法或生成式 AI 的正式备案评估
- 生产 AI 内容安全和模型安全评测

因此当前系统只适合本机检查和虚构数据演示。

## 3. 数据分类

| 等级 | 示例 | 默认规则 |
| --- | --- | --- |
| 高敏感 | 未满 14 周岁身份、生日、关系、学习画像、精细行为 | 加密、最小权限、单独同意、最短保存、禁止直接训练 |
| 敏感学习证据 | 原始答案、正确性、提示、重做、测试、能力维度 | 仅学习与报告用途，去标识分析，严格导出控制 |
| 运营数据 | 登录时间、错误日志、设备类别、支持工单 | 只收必要字段，设置短保存周期 |
| 公开课程数据 | 课程标准、原创题型元数据、通用知识图谱 | 记录来源和版本，确认版权及许可 |
| 模型资产 | 提示词、评测集、模型版本、缺陷案例 | 访问控制、版本签名、不可混入真实身份 |

生日只能作为年龄与合规判断、适龄界面或经验证的统计研究参数。不得把周易、星座或生日推断作为正式心理、能力、课程或机会决策，也不得向学生形成命运式标签。

## 4. 同意与角色

### 4.1 学生独立路径

产品流程不能强制存在老师。年龄和法律允许时，学生可以自行创建账号、填写基本信息、完成测试和学习；家长和老师通过邀请关系后成为可选观察者。

### 4.2 未满 14 周岁

《个人信息保护法》明确将不满 14 周岁未成年人的个人信息列为敏感个人信息，处理时应取得父母或其他监护人同意，并制定专门规则。[中国人大网](https://www.npc.gov.cn/WZWSREL25wYy9jMi9jMzA4MzQvMjAyMTA4L3QyMDIxMDgyMF8zMTMwODguaHRtbD9yZWY9aW1i)

建议流程：

```text
学生输入年龄范围
-> 系统判断是否需要监护人
-> 只保存待激活账号和最少信息
-> 监护人完成身份与同意
-> 激活学习数据处理
```

监护人同意不能被埋在一份总条款中。服务、教育研究、市场营销、同类比较和模型训练应分别说明。

## 5. 数据生命周期

| 阶段 | 必做控制 |
| --- | --- |
| 收集 | 字段最少化、用途说明、年龄适配、来源记录 |
| 传输 | HTTPS、证书管理、请求签名或会话保护 |
| 保存 | 中国境内区域评估、静态加密、密钥分离、租户隔离 |
| 使用 | 用途和角色授权、审计日志、管理员双人审批 |
| 分析 | 去标识、最小分组阈值、禁止还原个人 |
| 导出 | 水印、审批、字段脱敏、到期回收 |
| 删除 | 用户请求、关系解除和保存期到期均可触发 |
| 备份 | 与生产相同保护，删除请求能够覆盖备份生命周期 |

同类参照不得显示可识别的个人、班级小群体或精确可反推排名。当前五人阈值只用于虚构测试；真实上线应由统计和隐私评估确定更高的最低样本量，并优先显示区间或趋势。

## 6. 模型训练治理

### 默认禁止

以下内容默认不得进入通用模型训练：

- 姓名、联系方式、生日、学校、班级、精确位置
- 原始关系信息和账号标识
- 学生自由输入的敏感内容
- 可串联还原单个学生的完整时间线
- 未取得明确授权的数据

### 可进入受控改进的数据

必须同时满足：

1. 有明确且可撤回的用途授权或其他合法依据。
2. 已去除直接标识并降低链接攻击风险。
3. 数据质量、来源、版本和处理记录完整。
4. 划分训练、验证和永久隔离的测试集。
5. 输出经过隐私、偏差、年龄适宜性和内容安全评测。
6. 学生不同意模型改进时仍能获得同等核心服务。

生成式 AI 管理规则要求训练数据具有合法来源，涉及个人信息时取得同意或具备其他法律依据，并提高生成准确性、保护用户输入与使用记录。[国家网信办](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

## 7. 未成年人产品要求

《未成年人网络保护条例》自 2024-01-01 起施行，强调最有利于未成年人、网络素养、个人信息保护及防沉迷；对影响显著的平台还提出定期保护影响评估等要求。[国家市场监督管理总局转载的条例全文](https://www.samr.gov.cn/wljys/gzzd/art/2024/art_43b2ac59aefd427aabe333df54d68f0a.html)

对应产品要求：

- 不展示公开羞辱式排名，不用焦虑制造增长
- 学习时长有节制，不把停留越久定义为越好
- 使用温和的模糊进度，不显示倒计时式题量压力
- 提示促进思考，不直接替学生完成
- 家长控制不等于无限监控，学生应看到清晰的数据用途
- 提供投诉、纠错、删除和人工联系入口
- 对算法分配、画像和报告开展偏差检查

## 8. 上线备案与商业监管清单

上线前逐项由专业人员判断适用性：

- ICP 备案及必要的增值电信许可
- 网络安全等级保护定级、备案和测评
- 教育移动应用提供者备案；进入学校时评估使用者备案
- 个人信息保护影响评估和未成年人专门规则
- 网络数据安全、跨境传输和供应商委托处理协议
- 算法推荐备案适用性
- 面向公众的生成式 AI 备案、安全评估或已备案模型使用要求
- 教材、题目、图片、字体、音频及第三方模型的知识产权
- 义务教育学科类培训审批、收费、广告和融资限制

教育部的教育移动应用备案办法明确了提供者和机构使用者两类备案，并关联 ICP 和等级保护要求。[教育部备案办法](https://hudong.moe.gov.cn/srcsite/A16/s3342/201911/t20191122_409333.html) “双减”意见对义务教育阶段学科类校外培训实行严格监管，因此产品定位、收费和学校合作方式必须提前获得专项意见。[教育部公开文件](https://www.moe.gov.cn/jyb_xxgk/moe_1777/moe_1778/202107/t20210724_546576.html)

## 9. 生产安全验收门

- 高危和严重漏洞为 0
- 权限越权、会话固定、CSRF、XSS、注入和文件访问测试通过
- 备份恢复演练达到目标恢复时间和数据点
- 删除、导出、撤回同意流程通过
- 所有管理员操作可审计
- 供应商数据不用于其模型训练，除非另有明确授权
- AI 候选题可追溯到模型、提示、版本、验证和复核记录
- 安全事件响应联系人、时限、告知和演练完成
