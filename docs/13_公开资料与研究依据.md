# 公开资料与研究依据

检索截止：2026-09-08。链接用于说明本交付包的研究来源；任何第三方内容均不随代码重新分发。

## 1. 课程与市场规模

1. [教育部：2025 年全国教育事业发展统计公报](https://www.moe.gov.cn/jyb_sjzl/sjzl_fztjgb/202607/t20260706_1442870.html)  
   用途：全国义务教育和小学在校生规模。市场规模不等于可获得用户。

2. [教育部：义务教育课程方案和课程标准（2022 年版）](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)  
   用途：数学课程结构和课程对齐的国家基础。

3. [上海市教委：2025 年秋季中小学教学用书目录](https://edu.sh.gov.cn/xxgk2_zdgz_jcjy_04/20250718/f7cd3992f5044190a14f363a7e6a83f6.html)  
   用途：上海教材版本与五四学制语境。

4. [江苏省财政厅：省政协提案公开答复](https://czt.jiangsu.gov.cn/art/2024/6/27/art_77320_11281974.html)  
   用途：江苏学生相关公开规模口径。不能据此推断产品渗透率。

## 2. 教育研究

1. [NBER：Making AI Tutoring Productive](https://www.nber.org/papers/w35621)  
   2026 年、6,000 多名中学生随机实验。支持“结构化帮助嵌入错误后的练习”，也提醒掌握式推进本身不自动保证延迟学习增益。

2. [K-12 formative assessment meta-analysis](https://www.tandfonline.com/doi/abs/10.1080/13803611.2024.2363831)  
   汇总 118 项研究、258 个效应量，整体正向，但产品仍需自己的受控效果验证。

3. [Experimental Evidence of Tutoring for PreK-12 Learning](https://journals.sagepub.com/doi/10.3102/00028312231208687)  
   用途：一对一或小组辅导的证据背景和试点设计参考。

4. [Worked example and problem-solving study](https://doi.org/10.1016/j.cedpsych.2010.10.004)  
   用途：新手需要适当示例和支架，不能把“练中学”误解为无帮助试错。

5. [Worked-solution fading research](https://doi.org/10.1023/B:TRUC.0000021815.74806.F6)  
   用途：提示和完整示例应随独立能力逐步退出。

6. [Teaching with worked examples: problem selection](https://doi.org/10.1016/j.cedpsych.2024.102328)  
   用途：样题选择和歧义会影响学生形成的概念，支持题型语义验证门。

## 3. 法律、监管与安全

1. [中华人民共和国个人信息保护法](https://www.npc.gov.cn/WZWSREL25wYy9jMi9jMzA4MzQvMjAyMTA4L3QyMDIxMDgyMF8zMTMwODguaHRtbD9yZWY9aW1i)  
   用途：敏感个人信息、未满 14 周岁监护人同意和专门规则。

2. [未成年人网络保护条例](https://www.samr.gov.cn/wljys/gzzd/art/2024/art_43b2ac59aefd427aabe333df54d68f0a.html)  
   用途：最有利于未成年人、网络素养、个人信息保护、防沉迷和平台责任。

3. [生成式人工智能服务管理暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)  
   用途：公众生成式 AI 服务、训练数据来源、个人信息、准确性、未成年人和备案评估。

4. [教育移动互联网应用程序备案管理办法](https://hudong.moe.gov.cn/srcsite/A16/s3342/201911/t20191122_409333.html)  
   用途：教育应用提供者、机构使用者、ICP 和等级保护相关路径。

5. [“双减”意见](https://www.moe.gov.cn/jyb_xxgk/moe_1777/moe_1778/202107/t20210724_546576.html)  
   用途：义务教育阶段学科类校外培训、审批、收费和融资边界。

6. [互联网信息服务算法推荐管理规定](https://www.cac.gov.cn/2022-01/04/c_1642894606364259.htm)  
   用途：个性化分配算法的透明、用户权益和备案适用性评估。

## 6. 关键假设

- 时间、团队和预算区间均按现有代码可复用、人员能及时到位估计。
- 用户、付费率、ARPU 和估值倍数均是情景变量，不是预测。
- 产品尚未取得真实学习效果、商业收入或政府采购证据。
- 当前数据库只有虚构测试数据。
- 所有上线、融资和估值决定都需要独立专业复核。
