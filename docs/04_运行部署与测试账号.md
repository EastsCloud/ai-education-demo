# 运行部署与测试账号

## 1. 环境要求

- macOS、Linux 或 Windows 11
- Node.js 24 或更高版本
- 一个现代浏览器
- 建议至少 2 GB 可用内存和 500 MB 可用磁盘

不需要安装数据库，不需要执行 `npm install`，当前版本没有第三方运行时依赖。

## 2. 检查文件完整性

在交付包根目录执行：

```bash
shasum -a 256 -c MANIFEST.sha256
```

Linux 也可以使用：

```bash
sha256sum -c MANIFEST.sha256
```

Windows 可使用 PowerShell 的 `Get-FileHash` 对重点文件单独核对。

## 3. 启动五人测试快照

macOS / Linux：

```bash
./scripts/start-test-data.sh
```

Windows PowerShell：

```powershell
$env:PORT="4177"
$env:AI_EDUCATION_DATABASE_PATH="$PWD\runtime-data\system-e2e-it-review.sqlite"
Copy-Item .\test-data\system-e2e-final.sqlite $env:AI_EDUCATION_DATABASE_PATH -ErrorAction SilentlyContinue
node .\server\dev-server.mjs
```

然后打开：

```text
http://127.0.0.1:4177/
```

脚本会先复制测试快照，实际检查写入副本，不会修改原始基准数据库。若需要恢复：

```bash
RESET_TEST_DATA=1 ./scripts/start-test-data.sh
```

## 5. 启动干净系统

macOS / Linux：

```bash
./scripts/start-clean.sh
```

打开：

```text
http://127.0.0.1:4176/
```

第一次启动会创建 `runtime-data/ai-education-clean.sqlite`。IT 同事可以从登录页面注册全新学生、家长或老师，完整体验首次登录流程。

## 6. 新账号的推荐检查顺序

1. 注册一个学生账号。
2. 确认学生首先进入基本信息，而不是直接做题。
3. 完成两层性格测试，总题数不超过 12，页面不显示精确题号总数。
4. 学生选择数学并进入无提示初始能力测试。
5. 查看能力图，选择目标、学习周期、每日时间和每周频率。
6. 确认静态曲线后进入今日练习。
7. 故意答错一道题，检查原题重做、累积提示、一个数字和两个数字变式。
8. 完成后检查报告和知识图鉴。
9. 从学生账号生成家长或老师邀请码。
10. 注册成人账号，接受邀请码，再切换回学生核对同一数据。

## 8. 配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PORT` | `4176` | 本地 HTTP 端口 |
| `AI_EDUCATION_DATABASE_PATH` | `data/ai-education.sqlite` | 正常运行数据库 |
| `AI_EDUCATION_E2E_DATABASE` | `data/system-e2e-cohort.sqlite` | 五人自动测试数据库 |
| `AI_EDUCATION_E2E_REPORT_DIR` | `output/test-reports` | 自动测试报告目录 |
| `NODE_BIN` | `node` | 脚本使用的 Node 可执行文件 |

## 9. 健康检查

启动后访问：

```text
http://127.0.0.1:4176/api/health
```

应返回成功状态。若页面不断跳转，先确认只打开同一个端口，并清除该端口对应的旧会话 Cookie，再从 `/signin.html` 登录。

## 10. 备份与恢复

服务器停止后，复制当前 `.sqlite` 文件即可形成一致备份。运行中数据库采用 WAL 模式；如果必须热备份，需要同时处理 `.sqlite-wal` 和 `.sqlite-shm`，或改用 SQLite 官方备份机制。

测试环境最简单的恢复方式是删除 `runtime-data/` 下的工作副本，再从 `test-data/system-e2e-final.sqlite` 重新复制。不要删除交付包中的原始测试快照。

## 11. 安全提示

- 当前服务只绑定 `127.0.0.1`，不要通过端口转发直接暴露到公网。
- 不要把测试密码复用到任何真实环境。
- 正式部署必须增加 HTTPS、安全 Cookie、密钥管理、限流、审计导出、备份、告警和生产身份系统。
- 当前本地数据库中含虚构测试学生数据，不含真实学生数据。
