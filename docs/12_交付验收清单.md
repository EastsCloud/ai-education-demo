# 交付验收清单

版本：`1.0.0-semi-ai-mvp`  
建议验收人：项目所有者、IT 负责人、产品负责人、数学教研负责人。

## A. 文件与环境

- [ ] 压缩包能够正常解压，无系统提示损坏
- [ ] `MANIFEST.sha256` 校验全部通过
- [ ] `VERSION.txt` 与交付说明版本一致
- [ ] Node.js 版本为 24 或更高
- [ ] 包内没有真实学生个人信息
- [ ] 测试数据库、运行数据库和源代码目录分开

## B. 启动

- [ ] `./scripts/start-test-data.sh` 能启动五人测试快照
- [ ] `/api/health` 返回成功
- [ ] `./scripts/start-clean.sh` 能启动空白系统
- [ ] 空白系统不会读取测试快照
- [ ] 服务默认只绑定 `127.0.0.1`

## C. 账号与权限

- [ ] 测试学生、家长、老师均能登录
- [ ] 退出后受保护页面回到登录入口，不循环跳转
- [ ] 家长只能看到自己的学生
- [ ] 老师只能看到已建立关系的学生
- [ ] 学生可以不关联家长或老师独立完成流程
- [ ] 新成人关系通过一次性邀请码建立并可撤销
- [ ] IT 可以注册新账号，不依赖内置账号

## D. 新学生流程

- [ ] 新学生第一步是基本信息，不是直接做题
- [ ] 基本信息为标准选项，没有静默默认值
- [ ] 心理性格与学习性格是同一综合测试的两层
- [ ] 两层性格测试总量不超过 12 道
- [ ] 测试只显示模糊进度条，不显示题号 / 总题数
- [ ] 学生明确选择科目后才进入学科能力测试
- [ ] 学科能力测试没有提示或分步帮助
- [ ] 初始能力结果、目标、周期和学习强度能够形成静态曲线
- [ ] 学生确认静态曲线后才进入每日学习

## E. 每日练习

- [ ] 今日任务可从首页、练习和日历进入同一记录
- [ ] 每天只有一个必做事项：做题
- [ ] 错题必须先完成原题无提示重做
- [ ] 原题成功后按规则进入一个数字、两个数字变式
- [ ] 通过当前层级后才推进下一题
- [ ] 累积提示展开后保留前面提示
- [ ] 学生可先看自己以前的原题和答案再决定是否提示
- [ ] 分步引导要求学生逐步作答
- [ ] 支持多种已验证解题思路
- [ ] 完成必做后才出现自愿加练选择
- [ ] 对题、错题和同类型加练可选查看，不强推

## F. 曲线、图鉴与报告

- [ ] 日常作答只影响下一次出题，不直接更新动态曲线
- [ ] 只有正式阶段测试能确认新的曲线位置
- [ ] 超过静态曲线时可保持目标缩短时间，或保持节奏提高终点
- [ ] 不做选择时默认学习时长不变、终端水平自然变化
- [ ] 知识图鉴区分已掌握、进行中和未探索节点
- [ ] 图鉴能够回看知识点相关做题和错题
- [ ] 学生报告不显示后台画像或负面标签
- [ ] 家长和老师报告来自同一学生证据但展示更深分析
- [ ] 报告包含学习时间、提示率、独立正确率、重做成功率、趋势和同类参照
- [ ] 同类参照不泄露其他学生身份或答案

## G. 技术验证

- [ ] `./scripts/run-contracts.sh` 显示 `96 passed`
- [ ] `./scripts/run-five-learner-test.sh` 能创建新的独立数据库与报告
- [ ] 服务器重启后账号、关系、曲线、题目和报告仍存在
- [ ] 修改浏览器请求中的正确性字段不能伪造答对
- [ ] 学生响应不包含答案、种子、私有评分规则或行为标签
- [ ] 验证失败的题目候选不会交付
- [ ] 数据库备份和恢复步骤经 IT 实测

## H. 文档理解

- [ ] IT 能用自己的话解释“一对一、练中学、帮你学”
- [ ] IT 能指出半 AI 与全 AI 的边界
- [ ] IT 知道 41 个题型不等于上海课程完整覆盖
- [ ] 商业负责人理解免费注册不等于模型训练授权
- [ ] 所有人理解当前包不能直接暴露到公网
- [ ] 已知限制和下一阶段负责人已确认
