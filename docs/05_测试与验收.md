## 4. 测试发现并修复的问题

1. 家长和老师概览曾读取错误的报告层，导致真实行为存在但页面显示为空。
2. 观察端知识地图曾没有识别 API 的实际响应结构，显示了错误覆盖率。
3. 老师默认报告曾遗漏已经计算出的同类参照模块。
4. 自动测试曾使用 UTC 日期，洛杉矶本地页面可能显示“未来已完成”。
5. 账号切换曾可能进入登录重定向循环，现已验证真实学生、家长、老师切换。

修复后浏览器错误日志为 0，96 项合同全部通过。

## 5. IT 验收最低标准

IT 同事应完成 `12_交付验收清单.md`，至少确认：

- 文件校验值正确。
- 测试快照和干净系统都能启动。
- 学生、家长、老师账号均可登录。
- 老师能看到五名学生，家长不能看到其他学生。
- 新学生从基本信息开始，不继承测试学生数据。
- 题目答案不出现在浏览器公开响应中。
- 日常练习不直接改变动态曲线。
- 全部合同测试通过。
- 数据库重启后数据仍存在。

## 6. 当前测试不能证明什么

本轮测试不能证明：

- 数学内容已经逐章覆盖上海教材。
- 系统已经通过真实学生的教育效果验证。
- 系统能承受学校或省级并发量。
- 系统已经满足所有中国上线备案和未成年人合规要求。
- 全 AI 实时出题已经连接生产模型。

这些不是隐藏缺陷，而是下一阶段必须单独验收的工作包。
