以下内容有意没有进入交付包：

- `entry-page-*.html` 等旧页面评审原型
- UI 方案比较页
- 历史数据库及 WAL / SHM 文件
- 失败或被替代的端到端测试报告
- 投资人 PPT 和视频草案
- 临时截图、PDF 渲染图和开发缓存

这样 IT 检查的是当前正式运行链路，不会把早期页面或过期数据误认为产品的一部分。
