## 6. 不应被重新引入的旧错误

- [ ] 不把老师设为必经节点
- [ ] 不要求家长必须存在；学生可独立完成流程
- [ ] 不让新学生直接进入做题或继承默认值
- [ ] 不混淆心理性格、学习性格与学科能力测试
- [ ] 不在能力测试中提供“帮你学”提示
- [ ] 不显示精确题号 / 总题数造成赶进度压力
- [ ] 不把计划和每日练习拆成两个学生主导航
- [ ] 不把知识图鉴放进主导航造成拥挤
- [ ] 不向学生展示后台画像和负面行为标签
- [ ] 不因复做错误而改写原来答对的记录
- [ ] 不让日常练习直接改变动态曲线
- [ ] 不把动态曲线、知识覆盖和正式达到水平混为一谈
- [ ] 不把题目生成器暴露成学生端功能
- [ ] 不把测试数据、模拟数据和真实生产数据混用

## 7. 产品决定检查点

开发每一个新模块前，应核对：

```text
是否体现一对一？
是否让学生在练中学？
是否帮学生思考而不是代替思考？
证据来自哪里，谁能看到？
是否只有正式测试能改变曲线？
题目能否重算、解释、回滚？
学生单独使用是否仍然完整？
是否增加了无必要的文字、卡片或导航？
是否收集了并不需要的数据？
```

这些项目应在完成时逐条打勾，而不是到发布前凭记忆补做。
